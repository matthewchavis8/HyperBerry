# CLAUDE.md

Project instructions live in [AGENTS.md](AGENTS.md). Read it before changing
anything. It covers the build commands, the layout, the subsystem layering, and
how commit messages and comments are expected to read. [STYLES.md](STYLES.md)
covers the shape of the code itself.

Keeping the guidance in one file rather than two copies is deliberate. Two copies
drift, which is the same problem the device tree generation exists to solve.
